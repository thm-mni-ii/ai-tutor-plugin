### Test A — df.head bug (1 turn)

**Question:** *"Ich habe folgenden Code geschrieben: df.head — Warum bekomme ich keine Ausgabe der ersten Zeilen?"*

**A / BASELINE:**
> Der Befehl df.head wird nicht ausgeführt, weil du die Klammern fehlen lässt. Du hast nur df.head geschrieben, was den Methoden-Referenziertext zurückgibt, aber nicht die ersten Zeilen des DataFrames ausgibt. Um die ersten fünf Zeilen anzuzeigen, musst du df.head() aufrufen. Wenn du mehr oder weniger Zeilen sehen möchtest, kannst du die Anzahl der Zeilen als Parameter übergeben, zum Beispiel df.head(10) für die ersten zehn Zeilen. Überprüfe also, ob du die Klammern bei head() nicht vergessen hast.

**A / NEW:**
> Es sieht so aus, als hättest du den Befehl df.head ohne Klammern geschrieben. In Python musst du Funktionen immer mit runden Klammern aufrufen, auch wenn sie keine Argumente benötigen. Der richtige Aufruf wäre df.head(). Überlege, warum das wichtig ist und welche Ausgabe du dann erhältst.

### Test B — IndexError, progressive hints (2 turns, same problem)

**Question (turn 1):** *"Mein Code wirft einen IndexError: for i in range(len(liste)): print(liste[i+1]) — was ist das Problem?"*
**Follow-up (turn 2):** *"Ich verstehe den Hinweis nicht ganz, kannst du konkreter werden?"*

**B turn1 / BASELINE:**
> Der Fehler tritt auf, weil du versuchst, auf ein Element zuzugreifen, das außerhalb des Bereichs der Liste liegt. Wenn die Liste zum Beispiel aus drei Elementen besteht, hat sie die Indizes 0, 1 und 2. In deiner Schleife greifst du mit `i+1` auf das nächste Element zu. Bei `i = 2` versuchst du also, auf `liste[3]` zuzugreifen, was nicht existiert. Überlege, wie du die Schleife so anpassen kannst, dass du nie außerhalb der Liste gehst. Eine mögliche Lösung wäre, die Schleife bis `len(liste) - 1` laufen zu lassen. Denke auch darüber nach, ob du alternativ eine andere Methode zur Iteration verwenden könntest, um den Fehler zu vermeiden.

**B turn2 / BASELINE:**
> Deine Schleife läuft von 0 bis len(liste) - 1. Wenn die Liste drei Elemente hat, läuft die Schleife also von 0 bis 2. In jedem Durchlauf gibst du liste[i+1] aus. Bei i = 2 versuchst du also, liste[3] auszugeben, aber es gibt nur Elemente an den Positionen 0, 1 und 2. Ändere die Schleifenbedingung so ab, dass sie nicht bis zum letzten Index geht, sondern bis zum vorletzten. Oder überlege, wie du die Liste so durchlaufen kannst, dass du immer das aktuelle Element und das nächste Element gleichzeitig hast. Ein Trick wäre, die Schleife um eins kürzer zu machen.

**B turn1 / NEW:**
> Der Fehler tritt auf, weil du versuchst, auf ein Element zuzugreifen, das außerhalb der Grenzen deiner Liste liegt. Wenn du `liste[i+1]` verwendest, greifst du auf das nächste Element zu, aber wenn `i` den größten Index deiner Liste erreicht, ist `i+1` bereits außerhalb des gültigen Bereichs. Überlege, wie du den Loop so anpassen könntest, dass du nie versuchst, außerhalb der Liste zu indexieren. Welche Bedingung müsstest du hinzufügen, damit du nur auf gültige Indizes zugreifst?

**B turn2 / NEW:**
> Schauen wir uns das konkret an: Deine Schleife läuft von 0 bis len(liste)-1. Wenn die Liste 3 Elemente hat, läuft i von 0 bis 2. Bei i=2 versuchst du, liste[3] aufzurufen. Aber die Liste hat nur Indizes 0, 1 und 2. Was passiert also, wenn du den letzten Index benutzt? Versuche, den maximalen Wert von i so zu begrenzen, dass du nie außerhalb der Liste kommst. Wie müsste deine Schleife also lauten, damit du immer auf ein gültiges Element zugreifst?
